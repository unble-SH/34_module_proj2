# 취약점 점검 대상 서비스
## 온라인 교육 관리 플랫폼
학생/강사 회원가입 및 로그인, 개인정보 열람 및 수정, 성적 관리 및 열람, 문의 게시판 작성 기능이 구현된 간단한 웹서비스입니다.<br><br>
파이썬 가상환경 활성화 후 콘솔에 다음의 명령어를 입력하여 필요 패키지를 다운로드받아 주세요<br>
`pip install -r requirements.txt`<br>
이후 다음의 명령어를 이용해 실행할 수 있습니다.<br>
`python app.py`<br>
실행 시 데이터베이스 파일은 자동생성되며, github에는 올라가지 않습니다.<br>
최초 실행 시 자동으로 생성되는 계정이 있습니다. 자세한 사항은 노션을 참고해주세요.<br><br>
모든 코드는 GPT에 의해 생성되었습니다. 취약점을 만들기 위해 의도적으로 필터링을 없앤 경우 해당 부분을 주석처리 했습니다.<br>
현재 주석처리된 부분은 문의글 확인 시 작성자 또는 강사인지 확인하는 부분입니다.<br>
향후 취약점이나 기능을 추가하는 경우 노션에 업데이트 하겠습니다.<br>
